The whole internet in one word: **enshittification**. The platforms began by being useful, then sold the users to the advertisers, then sold the advertisers to the shareholders — and now everything is a feed trying to keep you scrolling past things you never asked for. One word names the whole arc, and it is funny precisely because it is accurate. Built for make.fun's "The Internet in One Word" bounty, $10 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the word to `/output/entry.txt` (UTF-8, one word, no trailing newline) and prints it. It is deterministic: two runs write byte-identical output.
